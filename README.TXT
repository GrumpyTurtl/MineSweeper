

PROJECT TITLE: Minesweeper

VERSION or DATE: 1.1
HOW TO START THIS PROJECT: run the void main(string[] args) func inside Main
AUTHORS: Oli
HOW TO INSTALL:
To run the game the first time you need to include the libraries. this is done by going to Tools > Preferences > Libraries and adding all the jar's inside lwjgl/.
you then need to restart the Java Runtime via Tools > Reset Java Virtual Machine. Finally run the project by starting the main function.
